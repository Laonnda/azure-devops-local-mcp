ado-mcp — Azure DevOps connector for Claude Desktop
======================================================

What is this?
-------------
ado-mcp lets Claude Desktop talk to your Azure DevOps organisation.
Once connected, you can ask Claude in plain language to look up work items,
review pull requests, trigger pipelines, search code, and more.


Before you start
----------------
You need Node.js installed on your PC.

  1. Go to https://nodejs.org
  2. Download the LTS version (the button on the left)
  3. Run the installer and click through with all defaults

If Node.js is already installed you can skip this step.


Installation
------------
  1. Extract this ZIP to a permanent folder, for example:
       C:\tools\ado-mcp

  2. Right-click setup.ps1 and choose "Run with PowerShell"
     (If Windows asks whether to allow it, click "Run anyway")

  3. Follow the prompts:
       - Azure DevOps URL   e.g. https://dev.azure.com/your-org
       - Personal Access Token  (see below)
       - Default project name   (optional)

  4. Restart Claude Desktop


Personal Access Token
---------------------
A Personal Access Token (PAT) proves to Azure DevOps that you are allowed
to use ado-mcp on your behalf. To create one:

  1. Open Azure DevOps and click your profile picture (top right)
  2. Choose "Personal access tokens"
  3. Click "+ New Token"
  4. Give it a name, e.g. ado-mcp-claude
  5. Set an expiry date (90 days is a good starting point)
  6. Under Scopes, choose "Custom defined" and tick what you need:

     Work items (read/write)    ->  Work Items - Read & Write
     Pull requests (read)       ->  Code - Read
     Pull request comments      ->  Code - Read & Write
     Pipelines                  ->  Build - Read & Execute
     Wiki                       ->  Wiki - Read & Write

  7. Click Create and COPY THE TOKEN IMMEDIATELY
     Azure DevOps only shows it once.

  Keep your token private — treat it like a password.


Verify the connection
---------------------
Open Claude Desktop and look for the tools icon (hammer) in the chat input.
Click it — you should see "ado" listed. If not, check Troubleshooting below.


Troubleshooting
---------------
"Run with PowerShell" does nothing or closes immediately
  -> Hold Shift and right-click setup.ps1, choose "Open with PowerShell"
     so you can see any error messages.

Node.js not found
  -> Install Node.js from https://nodejs.org (LTS version) and try again.

Claude Desktop does not show the ado tools after restart
  -> Make sure you extracted to the exact same folder you ran setup.ps1 from.
     The config file stores the full path to that folder.
  -> Check that Claude Desktop is fully closed and reopened (not just minimised).

Token rejected / authentication error
  -> The token may have expired or been created with wrong scopes.
     Go to Azure DevOps and create a new token, then run setup.ps1 again.
